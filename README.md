# Leonardo Barros · Portfólio

Uma viagem 3D pelo espaço em seis paradas (início, perfil, habilidades, missões, projetos e contato), em português e inglês.

Planetas, nebulosa, anéis e o foguete são gerados por código, com shaders próprios e iluminação em estilo cel, sem modelos prontos.

## Stack

React 19 · TypeScript · Vite · Three.js / React Three Fiber · Zustand

## Rodando localmente

```bash
npm install
npm run dev
```

Abre em http://localhost:5173.

## Navegação

- Scroll, ↑ ↓ ou as teclas 1–6 trocam de parada; Esc volta ao início.
- Em missões e projetos, ← → alternam entre os itens.
